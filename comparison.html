Algorithm Summaries & Academic Explanations

Linear Regression

Models linear relationship between academic predictor variables and final marks score using weighted coefficients \( y = \beta_0 + \beta_1 x_1 + \dots \).

Random Forest

Ensemble of decision trees trained on random subsets of data and features. Aggregates predictions to prevent overfitting and capture non-linear patterns.

Support Vector Machine (SVM)

Constructs optimal hyperplanes in multi-dimensional feature space to maximize decision margin between PASS and FAIL student classes.

Naive Bayes

Probabilistic classifier based on Bayes' Theorem with conditional independence assumption between student attendance, study hours, and backlogs.

K-Means Clustering

Unsupervised partition algorithm grouping students into K=3 clusters based on centroid Euclidean distance minimization across academic features.

Logistic Regression

Transforms linear combinations of student parameters using the Sigmoid function to output probability estimations for PASS/FAIL binary outcome.
