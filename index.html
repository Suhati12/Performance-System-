Core System Modules

Comprehensive AI analytics workflow for academic evaluation

1. Marks Regression

Predicts continuous final exam marks using Linear Regression and Random Forest Regressor models evaluated via MSE, RMSE, MAE, and R².

2. Pass/Fail Classification

Evaluates 5 classification models (Logistic Regression, Decision Tree, Random Forest, SVM, Naive Bayes) with confusion matrix diagnostics.

3. Academic Risk Engine

Flags High, Medium, and Low academic risk students based on attendance threshold, study hours, backlogs, and ML model predictions.

4. K-Means Clustering

Groups students into logical behavioral clusters (High Performing, Average Performing, At Risk) optimized via the Elbow Method.

5. Visual Analytics

Generates publication-quality Seaborn and Matplotlib diagnostic charts (actual vs predicted, residual distribution, confusion matrices, elbow plot).

6. Interactive Web Interface

Allows instant student input parameter evaluation, dynamic risk breakdown factor explanation, and live database record filtering.
